# Mathematics

## Overview 

### Math Operations

This sample ruleset shows how to do common math operations.

Powered by mathjs. Supports statistics, trigonometry, matrices, probability among many others


## Logic
- Use functions and constants as defined in mathjs https://mathjs.org/

## Concepts
- Apart from matrix definition, every declaration remains the same
- Use this format [[1,2,3],[4,5,6]] instead of the mathjs internal: ie [1, 2, 3; 4, 5, 6] which is not very idiomatic in this space
